INTRODUCCIÓN

¿Qué es Git?

Git es un sistema de control de versiones que permite registrar los cambios realizados en un proyecto. Puedes recuperar versiones anteriores y trabajar con diferentes ramas.

💡 ¿Para qué sirve?

  • Guardar el historial de cambios.
  • Recuperar versiones anteriores.
  • Trabajar en equipo.
  • Crear ramas independientes.
PLATAFORMA

¿Qué es GitHub?

GitHub es una plataforma que permite alojar repositorios Git en internet y colaborar con otros desarrolladores.

🚀 Características principales

  • Almacenar proyectos en la nube.
  • Compartir código.
  • Trabajar mediante Pull Requests.
  • Reportar errores con Issues.

⚙️ Instalación de Git

Descarga Git desde su página oficial:

Descargar Git →

Comprueba la instalación desde la terminal:

git --version

🔧 Configuración inicial

Configura tu nombre y correo electrónico:

Configurar usuario

git config --global user.name "Tu Nombre"

Configurar correo

git config --global user.email "correo@email.com"

Ver configuración

git config --list

📁 Comandos de repositorios

Inicializar un repositorio

git init

Clonar un repositorio

git clone URL_DEL_REPOSITORIO

Ver el estado del proyecto

git status

📝 Seguimiento de cambios

Agregar todos los archivos

git add .

Agregar un archivo específico

git add index.html

Guardar cambios

git commit -m "Mi primer commit"

Consultar historial

git log --oneline

🌿 Comandos de ramas

Ver ramas

git branch

Crear una rama

git branch nueva-rama

Cambiar de rama

git switch nueva-rama

Crear y cambiar de rama

git switch -c nueva-rama

Unir ramas

git merge nueva-rama

☁️ Comandos de GitHub

Conectar repositorio remoto

git remote add origin URL

Ver repositorios remotos

git remote -v

Subir cambios a GitHub

git push -u origin main

Descargar cambios del repositorio

git pull origin main

Descargar cambios sin fusionarlos

git fetch

🚀 Flujo de trabajo básico

Este es el proceso habitual para subir tus cambios:

01. Crear o modificar archivos
02. git status
03. git add .
04. git commit -m "Cambios"
05. git push origin main
